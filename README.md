## Overview

**FormifyAI** is a full-stack AI-powered SaaS application that automatically generates dynamic, customizable forms based on user prompts. Built using cutting-edge technologies like **Next.js** and **JavaScript**, FormifyAI leverages AI to simplify form creation, saving time and eliminating the need for manual configurations.

FormifyAI supports multiple input types such as checkboxes, radio buttons, combo boxes, and more. It also includes robust error-handling mechanisms for file uploads and allows users to update or delete incorrect files.

## Features

- **AI-Powered Form Generation**: Create forms dynamically by simply providing a prompt.
- **Multiple Input Fields**: Supports text inputs, checkboxes, radio buttons, combo boxes, and select options.
- **Error Handling**: Users can update or delete uploaded files and correct errors efficiently.
- **Seamless Integration**: Easily integrates with APIs to fetch and populate form data.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Customizable Options**: Allows for custom labels and values for select, radio, and checkbox inputs.

## Technologies Used

- **Frontend**: Next.js, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB (or any database you're using)
- **AI/ML**: GPT-4 API (or ChatGPT API) for form creation
- **Storage**: Amazon S3 (for file handling)
- **Authentication**: Clerk (for user authentication)
- **ORM**: DrizzleORM
- **Hosting**: Vercel

## Installation

### Prerequisites

- Node.js (>= 14.x)
- npm or yarn
- MongoDB or any database you're using
- Amazon S3 account (for file uploads)
- Clerk API keys (for authentication)




## Usage
Sign up or log in using Clerk's authentication.
Use the AI-powered form generator by providing a prompt.
Customize form fields (checkboxes, radios, selects) with values and labels as needed.
Upload files and handle errors with the built-in file management system.
View and manage your created forms through the dashboard.
